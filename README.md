# 🍽️ 오늘 뭐 먹지? (Random Menu)

매일 고민되는 식사 시간을 해결해 주는 인터랙티브 랜덤 메뉴 추천 웹 애플리케이션입니다.  
카테고리(전체, 한식, 중식, 일식, 양식 등)를 선택하고 룰렛을 돌려 오늘 먹을 최적의 메뉴를 추천받아보세요! 🎉

---

## ✨ 주요 기능
- **다양한 카테고리 필터**: 전체, 한식, 중식, 일식, 양식 등 테마별 메뉴 제공
- **생동감 넘치는 인터랙션**: 부드러운 애니메이션과 축하 효과(Confetti)
- **반응형 웹 디자인**: 모바일 및 데스크톱 환경 모두에 최적화된 모던 UI
- **손쉬운 사용성**: 별도의 설치 없이 브라우저에서 바로 실행 가능

## 🛠️ 기술 스택
- **HTML5** & **CSS3** (모던 스타일링 및 반응형 레이아웃)
- **Vanilla JavaScript** (ES6+)
- **Pretendard Font**
- **Canvas-Confetti**

## 🚀 실행 방법
1. 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 더블 클릭하여 웹 브라우저에서 바로 열 수 있습니다.
